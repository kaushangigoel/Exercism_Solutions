# Exercism Solutions

A collection of my solutions to programming exercises from [Exercism](https://exercism.org/).

The goal of this repository is to document my progress, practice problem-solving, and improve my understanding of programming concepts through hands-on exercises.

## 📚 About Exercism

[Exercism](https://exercism.org/) is a free platform that provides coding exercises across a wide range of programming languages. It focuses on building programming fluency through practice, mentoring, and feedback.

This repository contains my personal solutions to exercises completed on the platform.

## 🗂️ Repository Structure

Solutions are organized by programming language and track.

```text
Exercism_Solutions/
│
├── TypeScript/
│   ├── exercise-1/
│   ├── exercise-2/
│   └── ...
│
└── ...
```

As I work through additional Exercism tracks, more languages and solutions may be added.

For each exercise, I try to focus on understanding the underlying problem rather than simply arriving at a working solution.

Where appropriate, solutions aim to emphasize:

* Clear and expressive code
* Appropriate use of language features
* Simplicity over unnecessary complexity
* Readability and maintainability
* Good programming practices

The solutions may evolve over time as I learn better approaches.

## 🚀 Running the Solutions

The exact setup and commands depend on the language and Exercism track.

For TypeScript solutions, you will generally need:

* [Node.js](https://nodejs.org/)
* npm
* TypeScript

After cloning the repository:

```bash
git clone https://github.com/kaushangigoel/Exercism_Solutions.git
cd Exercism_Solutions
```

Individual exercises may contain their own tests or configuration based on the Exercism track requirements.

## 🧪 Testing

Exercism exercises are generally accompanied by test suites.

When working on a particular exercise, run the tests associated with that exercise to verify the implementation.

For example, depending on the project setup:

```bash
npm test
```

or the appropriate test command provided by the exercise.
